# Explainable AI for Rice Leaf Disease Classification

This repository provides the implementation of a lightweight deep learning model based on MobileNetV2 integrated with Grad-CAM for rice leaf disease classification.

## Dataset

The dataset consists of rice leaf images categorized into:

* Bacterial Leaf Blight
* Brown Spot
* Leaf Smut

## Methodology

* Transfer Learning using MobileNetV2
* Image preprocessing (resize, normalization, augmentation)
* Explainability using Grad-CAM

## Results

* Training Accuracy: 97.79%
* Validation Accuracy: 95.8%

## How to Run

1. Install dependencies:

```
pip install -r requirements.txt
```
